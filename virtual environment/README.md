# Virtual Environment Practice Projects

This folder contains the Python practice projects from the uploaded archive.

## Projects

- `ATM/` - console-based ATM program.
- `crud_app/` - MySQL CRUD practice.
- `ecommerce/` - MySQL country, state and city tables.
- `Library-Management-System/` - SQLite library database practice.
- `sms-app/` - SQLite student management database practice.
- `SQLLITE- CONNECT/` - SQLite users, location and normalized ecommerce tables.

## About the uploaded environments

The original archive included complete Windows virtual environments and installed package files. Those generated environment folders are intentionally not copied into Git because they contain thousands of machine-specific files and are not portable.

Create a fresh environment on your computer for each project when needed, then install its dependencies. Python source files are preserved here.

The SQLite database files from the archive are not included in this upload; the scripts create their databases when run.
