## 📁 File Handling

### 📖 What is File Handling?

File handling is the process of reading data from files and writing data to files.

It allows you to interact with files on a computer, enabling data to be stored and retrieved persistently.

File handling is useful for tasks such as storing login data and managing configuration files.

Python provides built-in functions and methods that make it easier to read, write, and create files.

### 🧰 Functions Used in File Handling

1. **`open()`**: open a file and return a file object.
2. **`read()`**: reads and returns the contents of a file.
3. **`write()`**: writes a string to a file.
4. **`close()`**: closes an open file.
5. **`with` statement**: manages a file context and automatically closes the file when the block ends.
6. **`seek()`**: move the file pointer to a specific position in the file.
7. **`tell()`**: return the current position of the file pointer.
8. **`flush()`**: forces buffered data to be written to the underlying file.
9. **`readline()`**: reads and returns one line from a file.
10. **`readlines()`**: reads all remaining lines and returns them as a list of strings.
11. **`writelines()`**: writes an iterable of strings to a file. It does not add newline characters automatically.
12. **`truncate()`**: resizes a file to a specified size.
13. **`os.remove()`**: deletes a file from the file system.
14. **`os.rename()`**: renames a file or directory.
15. **`os.path.dirname()`**: returns the directory portion of a path.

### 📂 File Handling Modes

Python provides different file modes for reading, writing, and appending data to files.

1. **`r`**: opens a file for reading. The file must already exist.
2. **`r+`**: opens an existing file for both reading and writing. It does not erase the existing contents.
3. **`w`**: opens a file for writing. It creates the file if it does not exist and erases existing contents if it does.
4. **`w+`**: opens a file for both reading and writing. It creates the file if needed and erases existing contents.
5. **`a`**: opens a file for appending. New data is added at the end; the file is created if it does not exist.
6. **`a+`**: opens a file for both reading and appending. The file is created if it does not exist.
