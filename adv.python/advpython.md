## 📁 File Handling 

### 📖 What is File Handling?

File handling is the process of reading data from files and writing data to files.

It allows you to interact with files on a computer, enabling data to be stored and retrieved persistently.

File handling is useful for tasks such as storing login data and managing configuration files.

Python provides built-in functions and methods that make it easier to read, write, and create files.

### 🧰 Functions Used in File Handling

1. **`open()`**: open a file and return a file object.
2. **`read()`**: read the cntent of the file.
3. **`write()`**: write a data into file.
4. **`close()`**: close a open file.
5. **`with` statement**: with is an statement used in File Handling that can automatically close the file after there situation.
6. **`seek()`**: move the file pointer to a specific position in the file.
7. **`tell()`**: return the current position of the file pointer.
8. **`flush()`**: flushes the internal buffer that can be all data write on the file.
9. **`readline()`**: read single line.
10. **`readlines()`**: read all lines of the line and return a file as list.
11. **`writelines()`**: write a list/line of string to the files.
12. **`truncate()`**: truncate the file of specific value.
13. **`os.remove()`**: simple module that used to remove a file from file system.
14. **os.remove():** rename a file from the file system.
15. **`os.path.dirname()`**: returns a directory name of a file.

### 📂 File Handling Modes

Python provides different file modes for reading, writing, and appending data to files.

1. **`r`**: read mode used to open file and read file if file does not exist cannot create new file.
2. **`r+`**: read and write mode used to write content in files, if file does not exist cannot create new file.
3. **`w`**: write mode used to owrite content in file and if file does not exist  create new file.
4. **`w+`**: open a file to read | write content | if file does not exist cannot create new file.
